## Quick Start

1. **Wait 10-20 seconds** for the server to fully start
2. **Open browser:** http://localhost:3000
3. **Click "+ New Analysis"**
4. **Upload your CSV file**
5. **Start analysis!**

---

## If It's Not Loading

- Wait a bit longer (first start can take 20-30 seconds)
- Check terminal for any error messages
- Make sure port 3000 isn't already in use
- Try refreshing the page
