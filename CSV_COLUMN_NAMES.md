# CSV Column Names Supported

## Payout Columns
The system now supports these payout column name variations:
- `payout`
- `Payout`
- `Payout Amount`
- `payout_amount`
- `Payout_Amount`
- `CPL Buyer Payouts`
- `Duration Buyer Pay`
- `CPL`

## Location Columns
- **City:** `city`, `City`, `CITY`, `city_name`
- **State:** `state`, `State`, `STATE`, `state_id`
- **Zip:** `zip`, `Zip`, `ZIP Code`, `Zip Code`, `zip_code`

## Niche Column (Optional)
- `niche`, `Niche`, `category`, `Category`

---

**Tip:** Your CSV can use any of these column name variations and they'll be recognized automatically!
